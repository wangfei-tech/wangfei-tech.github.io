弓字形路径的基本动作很简单：走完一条扫描带，横向移动一小段，再沿相反方向走下一条。困难在于，遇到障碍物和凹形边界后，同一条扫描线上的可通行部分可能断开。Cell 分解把复杂自由空间切成适合往复覆盖的区域，再安排区域之间的访问顺序。

本文讨论 Boustrophedon Cellular Decomposition（BCD）。它将区域内覆盖与区域间连接分开处理：前者生成往复路径，后者在 Cell 邻接图上组织遍历。这一思路可参见 [Choset 与 Pignon 的原始工作介绍](https://publications.ri.cmu.edu/coverage-path-planning-the-boustrophedon-decomposition)。

以下扫描线例子、数据结构和伪代码是原理教学示例，不是对某一工程源码的逐行说明。

## 1. Cell 是什么？

Cell 是自由空间中的一个连通子区域，不等于地图上的单个栅格。

设扫描线为竖直线 x = s，沿 X 方向从左向右移动。对一个适合这种扫描方式的 Cell，在其内部的任意普通位置，扫描线与它的交集都是一个连续区间：

```text
I(s) = [y_top(s), y_bottom(s)]
```

Cell 可以有倾斜或弯曲的上下边界，不要求是矩形，也不要求是凸多边形。这里要求的是相对于扫描方向的单调性：在一个普通切片上，不会出现属于同一个 Cell 的两个分离自由区间。

临界位置处可能有边界接触或退化区间，不能简单套用普通切片的配对规则。

## 2. 一个障碍物为什么产生四个 Cell？

考虑矩形房间中有一个矩形障碍物。竖直扫描线由左向右移动：

```text
             障碍物左端          障碍物右端
                  a                  b
  ┌───────────────┬──────────────────┬──────────────┐
  │               │      B           │              │
  │      A        ├──────────────────┤      D       │
  │               │     障碍物       │              │
  │               ├──────────────────┤              │
  │               │      C           │              │
  └───────────────┴──────────────────┴──────────────┘
```

图中的 a、b 是人为添加的分解边界，可在自由空间部分跨越，不是实体墙。

| 扫描位置 | 扫描线上的自由区间 | Cell 处理 |
| --- | --- | --- |
| 障碍物左侧 | 一个完整区间 | 延续 A |
| 跨过障碍物左端 a | 一个区间变成上下两个 | 结束 A，创建 B、C |
| 障碍物中部 | 上下两个区间 | 分别延续 B、C |
| 跨过障碍物右端 b | 两个区间重新连成一个 | 结束 B、C，创建 D |

核心不是发现某个点坐标变化，而是发现自由区间的连接关系变化。

## 3. 普通边界变化与拓扑变化

房间的上边界斜了一点，扫描区间的端点就会移动，但一个区间仍然对应一个区间，此时可以继续同一个 Cell。

障碍物开始挡住扫描线时，一个区间变成两个，需要分裂；障碍物结束时，两个区间变成一个，需要合并。

一般可按事件前后区间的连接关系理解：

| 事件 | 局部连接变化 | 操作 |
| --- | --- | --- |
| 延续 | 1 → 1 | 保持 Cell 编号，更新边界 |
| 出生 | 0 → 1 | 创建 Cell |
| 消亡 | 1 → 0 | 结束 Cell |
| 分裂 | 1 → 多个 | 结束旧 Cell，创建后继 Cell |
| 合并 | 多个 → 1 | 结束旧 Cell，创建后继 Cell |

这里比较的是一个局部事件的连接关系。不能只比较整列自由区间的总数量：不同位置的分裂与合并可能同时发生，总数量保持不变。

Boustrophedon 分解关注自由切片连通性的变化。仅仅遇到一个普通拐角，不一定需要新建 Cell；这也是理解其分解方式的关键。

## 4. 扫描线如何得到自由区间？

假设图像坐标 Y 向下。在某条不穿过临界点的扫描线上，边界按 Y 递增排列：

```text
y =   3  外墙上边界  CEILING
y =  85  障碍物上边界 FLOOR
y = 104  障碍物下边界 CEILING
y = 297  外墙下边界  FLOOR
```

对应的两个自由区间为：

```text
上部自由区间：[3, 85]
下部自由区间：[104, 297]
```

这里的 CEILING/FLOOR 是一种工程命名约定：分别表示自由区间的上、下边界。障碍物顶部结束上方自由区间，因此是 FLOOR；障碍物底部开启下方自由区间，因此是 CEILING。

如果边界类型依赖轮廓遍历方向，就必须先统一输入方向。这个输入约束属于具体分类器实现，不是 Cell 分解理论本身的要求。相关实际案例见 [弓字形路径异常排查项目](/projects/boustrophedon-contour-direction/)。

对于穿过顶点、沿竖直边重合或多个事件同 X 的扫描线，需要统一端点包含规则，并结合事件两侧的状态判断；直接把所有边界点两两配对会产生歧义。

## 5. 如何判断相邻切片的对应关系？

关键问题是：前一个切片的哪个区间，能够连续到达后一个切片的哪个区间？

在栅格实现中，可以逐列提取自由像素段，并根据明确的 4 邻接或 8 邻接规则建立跨列连接；在几何实现中，需要根据临界事件与中间区域的几何关系建立连接。

**相邻采样列的 Y 区间是否重叠，只能在满足采样和几何假设时作为近似判据。** 对斜向通道、薄障碍物或较大的采样步长，单纯重叠判断可能误判。精确分解应处理所有相关临界位置；离散实现的结果则受地图分辨率和连通性约定限制。

教学伪代码如下：

```text
对每个扫描位置或事件组：
    提取当前自由区间
    建立前后区间的连接关系
    按局部连接关系分组：
        1 → 1：延续 Cell
        0 → 1：创建 Cell
        1 → 0：结束 Cell
        1 → 多：结束前驱，创建各后继并记录邻接
        多 → 1：结束各前驱，创建后继并记录邻接
        更复杂的同时事件：按事件组统一处理
    保存当前活跃 Cell 与对应区间
结束扫描时关闭剩余 Cell
```

工程上还需要处理零宽通道、边界接触、同时事件和噪声。事件组不能随意依赖容器的遍历顺序更新，否则同一输入可能得到不同拓扑。

## 6. Cell Graph 保存了什么？

每个 Cell 是一个节点。两个 Cell 在分解边界处具有可通行连接时，在图中建立边。

前面的矩形障碍物示例形成：

```text
       B
      / \
     A   D
      \ /
       C
```

也就是 A—B、A—C、B—D、C—D。

节点保存区域边界等几何信息；边最好保存可跨越的接口或 portal，便于规划区域之间的转移路径。两个区域仅在一个点相接，并不代表真实机器人能通过。

Cell Graph 表示连接关系，不直接等于最终运动轨迹。遍历时可能重复经过已覆盖区域，也不保证总路径最短。为每个 Cell 选择入口、出口和覆盖方向，会影响转移距离与掉头次数。

## 7. 从 Cell 边界生成弓字形路径

假设区域已经转换为机器人参考点能够安全运动的自由空间。在 Cell 内选取扫描位置：

```text
x_0, x_1, x_2, …, x_n
```

在每条扫描线上求有效自由区间，再交替走向：

```text
x_0：上 → 下
x_1：下 → 上
x_2：上 → 下
```

连续扫描段之间用可行的转弯轨迹连接；跨 Cell 时，通过邻接接口与转移规划器连接。

扫描间距不能只根据栅格大小决定。若工具的有效覆盖宽度为 w，期望重叠宽度为 o，可把 d ≤ w - o 作为平行直线段的间距设计起点。它并不单独保证全覆盖：第一条和最后一条路径到边界的距离、工具安装偏移、定位误差以及转弯段，都要一起检查。

机器人外形与工具覆盖范围承担不同职责。障碍物膨胀或配置空间建模用于保证机体安全；工具扫掠范围用于判断是否覆盖目标区域。不能把两者都简化成同一个半径。

即使 Cell 能用往复线段覆盖，真实机器人仍可能受最小转弯半径、倒车能力和狭窄空间约束影响，需要检查可执行性。

## 8. 如何验证分解正确？

建议从几何、拓扑、覆盖三个层面检查。

- **几何：**各 Cell 的内部不应互相重叠，它们的并集应恢复目标自由空间，允许共享分解边界；栅格实现应明确像素归属规则。
- **拓扑：**图中每条边都应对应真实可通行的连接；每个可达 Cell 都应能在图中从起始区域访问。
- **覆盖：**机体运动应无碰撞，工具扫掠区域应覆盖目标，转移路径与转弯也应可执行。

边界容器数量相同并不足以证明正确。如果上下边界分别保存折线顶点，顶点数量可以不同；应在相同扫描位置插值求交，再判断区间。只有采用同列一一配对采样的数据结构时，才要求对应数组按约定配对。

调试时可分别画出地图轮廓、事件散点、带编号的 Cell、邻接接口和最终路径。这几层分开后，更容易判断错误发生在输入、分类、分解还是运动连接环节。

## 9. 一个便于记忆的处理流程

```text
明确自由空间与机器人约束
    → 选定扫描方向
    → 提取自由区间
    → 跟踪区间的延续、分裂与合并
    → 构建 Cell 与邻接接口
    → 安排 Cell 访问顺序
    → 生成区域内往复路径
    → 连接并验证完整运动轨迹
```

Cell 分解解决的是“复杂区域如何拆成容易覆盖的子区域”。它与区域访问顺序、转移路径、运动约束和工具覆盖模型共同组成完整的覆盖规划系统。
